# 暁の勇者

`RPG_SPEC.md` に沿った短編ブラウザ RPG。Vite、TypeScript、Phaser 3 で動作します。画像は `assets/medieval_rpg/` を使用しています。

## 起動

```sh
npm install
npm run dev
```

表示された URL をブラウザで開きます。配布用ビルドは `npm run build`、確認は `npm run preview` です。

## 操作

- 矢印キー: 移動（WASD も使用可）
- Enter / Space / Z: 会話・調べる
- Esc / X: メニュー
- 画面内のコマンドはクリックで選択可能

街で準備をしてフィールドを北上し、城の竜を倒して魔王に挑みます。探索メニューからセーブできます。ロードできないデータは新規開始で遊べます。
